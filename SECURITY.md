# Security Policy

## Supported Versions

We actively support and patch the latest major release of `NanoSearch`.

| Version | Supported |
| --- | --- |
| v1.x.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public GitHub issue. Instead, report it directly by email to the maintainers or project owners. We will investigate the issue and issue a patch as quickly as possible.
